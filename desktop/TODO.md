# HomeMusic Desktop

Компактный плеер в духе AIMP: три размера одного окна, тёмно-серый фон, оранжевый акцент.
Сервер уже работает: Navidrome `http://192.168.1.51:4533`, Хаб `http://192.168.1.51:8080`.
Стек: Rust, интерфейс Slint, звук через libmpv. Свой декодер не пишем.

Примеры, на которые равняемся:

- большое окно — три колонки и оранжевая нижняя панель;
- среднее — обложка, кнопки и одна очередь;
- маленькое — полоска с названием, перемоткой и громкостью. Серый металл с того примера не повторяем, только размер и набор кнопок.

Дальше идём по шагам. Следующий шаг не начинаем, пока текущий не принят.

## 0. Каркас

Сделано в этом шаге.

- [x] Проект `desktop/`: Slint, три раскладки, переключение мини / сред / боль.
- [x] Общее состояние: название, позиция, громкость, играть / пауза / стоп. Звука ещё нет, полоса просто едет.
- [x] Заготовка Navidrome: `config.example.toml`, разбор `config.toml`, токен Subsonic `md5(пароль + salt)` без сетевого запроса.
- [x] `cargo build` собирает бинарник.

Как смотреть: на машине с экраном, из `desktop/`, `cargo run`. Здесь, на виртуалке, экрана нет, окно не открывается.

## 1. Маленькое окно

Привести мини-режим к плотной полоске.

- [x] Убрать временные подписи «мини / сред / боль» в нормальный переключатель, который не спорит с кнопками плеера.
- [x] Порядок как на маленьком примере: название и время, полоса перемотки, громкость, играть, стоп, следующий.
- [x] Окно запоминает, что его двигали. Пока можно оставить рамку ОС, без рамки будет в шаге 7.
- [x] Кнопки попадают в себя при ширине около 520 и высоте около 130.

Готово, когда мини-режим читается как плеер, а не как форма из подписей. На виртуалке без экрана это проверено сборкой, не взглядом.

## 2. Звук

- [x] Подключить libmpv. Сборка находит его через pkg-config.
- [x] Играть локальный файл, потом произвольный HTTP-адрес. Файл или адрес передаётся первым аргументом: `cargo run -- /путь/к/файлу.mp3`.
- [x] Пауза, стоп, перемотка и громкость идут в mpv, а не в таймер-заглушку.
- [x] Позиция и длительность читаются из mpv и двигают полосу.
- [x] Форматы библиотеки: MP3, Opus, M4A.

Готово, когда файл звучит и перемотка совпадает с тем, что слышно. На этой виртуалке нет экрана и звуковой карты: проверка через `ao=null`, позиция и перемотка совпали с часами mpv. Ушами здесь не слышно.

- [ ] `ping.view`.

Готово, когда мини-окно играет трек с сервера.

## 4. Среднее окно

- [ ] Сверху обложка, название, исполнитель, альбом, формат и кнопки.
- [ ] Ниже очередь: текущий трек оранжевой строкой, у остальных виден номер, название, длительность.
- [ ] Обложка берётся из Navidrome (`getCoverArt`). Пока обложки нет, остаётся тёмный квадрат.
- [ ] Полоса поиска пока только рисуется. Запрос к серверу — шаг 6.

Готово, когда среднее окно похоже на средний пример и показывает ту же очередь, что играет.

## 5. Очередь

- [ ] Клик по строке включает этот трек.
- [ ] Следующий и предыдущий ходят по очереди, а не по всей библиотеке.
- [ ] Источник очереди на первый раз: один плейлист Navidrome либо «все треки», если плейлиста нет.
- [ ] Внизу сумма длительности очереди.

Готово, когда можно пройти очередь кнопками и мышью, и после конца трека включается следующий.

## 6. Большое окно

- [ ] Слева «сейчас играет»: обложка, название, список треков текущего альбома или очереди.
- [ ] По центру библиотека: исполнители и альбомы из Navidrome. Вкладки Clouds, Podcasts и Local files не делаем.
- [ ] Справа та же очередь, что в среднем окне.
- [ ] Снизу оранжевая панель: кнопки, перемотка, время, громкость.
- [ ] Поиск по библиотеке фильтрует альбомы и очередь.

Готово, когда из альбома в центре можно собрать очередь и она сразу видна справа и в среднем окне.

## 7. Поведение окна

- [ ] Без стандартной рамки, своя полоска заголовка, перетаскивание, закрыть и свернуть.
- [ ] Маленькое окно умеет оставаться поверх остальных.
- [ ] Трей: свернуть в трей, двойной щелчок возвращает окно.
- [ ] Горячие клавиши: пробел, следующий, предыдущий, громкость. Пока глобальные медиа-клавиши можно не перехватывать.
- [ ] Запоминать режим, размер, положение и громкость между запусками.
- [ ] Настоящая волна на перемотке. До этого шага полоса остаётся ровной оранжевой.

Готово, когда плеер ведёт себя как небольшое окно AIMP, а не как обычная форма.

Готово, когда exe запускается двойным щелчком и играет библиотеку с `192.168.1.51`.

## Не делаем

- Свой звуковой декодер.
- Эмбеддер, миксы и ассистента внутри плеера. Это остаётся в Хабе.
- Редактор скинов AIMP. Рисуем свои три раскладки, а не загружаем чужой `.acs`.
