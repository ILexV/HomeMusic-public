# HomeMusic Desktop

Компактный плеер в духе AIMP: три размера одного окна, тёмно-серый фон, оранжевый акцент.
Сервер уже работает: Navidrome `http://192.168.1.51:4533`, Хаб `http://192.168.1.51:8080`.
Стек: Rust, интерфейс Slint, звук через libmpv. Свой декодер не пишем.

Примеры, на которые равняемся:

- большое окно — три колонки и оранжевая нижняя панель;
- среднее — обложка, кнопки и одна очередь;
- маленькое — полоска с названием, перемоткой и громкостью. Серый металл с того примера не повторяем, только размер и набор кнопок.

Дальше идём по шагам. Следующий шаг не начинаем, пока текущий не принят.

## 2. Звук

- [x] Подключить libmpv. Сборка находит его через pkg-config.
- [x] Играть локальный файл, потом произвольный HTTP-адрес. Файл или адрес передаётся первым аргументом: `cargo run -- /путь/к/файлу.mp3`.
- [x] Пауза, стоп, перемотка и громкость идут в mpv, а не в таймер-заглушку.
- [x] Позиция и длительность читаются из mpv и двигают полосу.
- [x] Форматы библиотеки: MP3, Opus, M4A.

Готово, когда файл звучит и перемотка совпадает с тем, что слышно. На этой виртуалке нет экрана и звуковой карты: проверка через `ao=null`, позиция и перемотка совпали с часами mpv. Ушами здесь не слышно.

## 5. Очередь

- [x] Клик по строке включает этот трек.
- [x] Следующий и предыдущий ходят по очереди, а не по всей библиотеке.
- [x] Источник очереди на первый раз: один плейлист Navidrome либо «все треки», если плейлиста нет.
- [x] Внизу сумма длительности очереди.

Готово, когда можно пройти очередь кнопками и мышью, и после конца трека включается следующий. На виртуалке без экрана и звуковой карты окно не открывалось и звук не слышен. Клик и кнопки сходятся в одну очередь, автопереход проверен короткими WAV через `ao=null`. С сервера взялся плейлист «Любимое из Spotify»: 47 треков, сумма 2:55:19, первый трек открылся через `ao=null`. Пустая очередь «все треки» вживую не понадобилась: плейлист есть.

## 6. Большое окно

- [x] Слева «сейчас играет»: обложка, название, список треков текущего альбома или очереди.
- [x] По центру библиотека: исполнители и альбомы из Navidrome. Вкладки Clouds, Podcasts и Local files не делаем.
- [x] Справа та же очередь, что в среднем окне.
- [x] Снизу оранжевая панель: кнопки, перемотка, время, громкость.
- [x] Поиск по библиотеке фильтрует альбомы и очередь.

Готово, когда из альбома в центре можно собрать очередь и она сразу видна справа и в среднем окне. На виртуалке без экрана и звуковой карты окно не открывалось и звук не слышен. С сервера прочитаны 107 исполнителей и 128 альбомов, первый альбом отдал треки, поиск по имени альбома вернул альбом. Клик по альбому кладёт эти треки в ту же очередь, что видна справа и в среднем окне. Поиск прячет чужие строки очереди и не сдвигает их номера. Мышью по окну здесь нажать нельзя.

## 7. Поведение окна

- [x] Без стандартной рамки, своя полоска заголовка, перетаскивание, закрыть и свернуть.
- [x] Маленькое окно умеет оставаться поверх остальных.
- [x] Трей: свернуть в трей, двойной щелчок возвращает окно.
- [x] Горячие клавиши, когда окно в фокусе: пробел, следующий, предыдущий, громкость.
- [x] Медиа-кнопки клавиатуры управляют плеером: играть / пауза, следующий, предыдущий, громкость. Команды доходят и когда окно не в фокусе.
- [x] Запоминать режим, размер, положение и громкость между запусками.
- [x] Настоящая волна на перемотке. До этого шага полоса остаётся ровной оранжевой.

Готово, когда плеер ведёт себя как небольшое окно AIMP, а не как обычная форма. На виртуалке без экрана и звуковой карты окно не открывалось и звук не слышен. Сборка и 32 теста прошли. Волна проверена на WAV: громкая половина выше тихой, тишина оставляет ровную полосу. Старый `window-place.toml` только с `x` и `y` по-прежнему читается. Горячие клавиши и двойной щелчок по трею проверены как чистые функции. Медиа-кнопки без фокуса идут через системный канал плеера; здесь нет сессии рабочего стола, поэтому значок трея и сами кнопки нажать нельзя. Мышью по рамке здесь тоже не провести.

## 8. Windows

- [x] Сборка под Windows: один exe, рядом libmpv или статическая связка, как получится проще.
- [x] `config.toml` рядом с exe.
- [ ] Проверка на том компьютере, где уже открыт Хаб: мини играет, среднее показывает очередь, большое открывает альбом.

Готово, когда exe запускается двойным щелчком и играет библиотеку с `192.168.1.51`.

На этой виртуалке нет экрана и звуковой карты: окно не открывалось и звук не слышен. Linux-сборка прошла, 35 тестов. Кросс-сборка дала `desktop/dist/windows/HomeMusic.exe` (PE32+, оконная подсистема, без консоли). Рядом лежат `libmpv-2.dll` и `vulkan-1.dll`: эта сборка libmpv тянет загрузчик Vulkan как обычную библиотеку, без него Windows не запустит exe. Туда же скопирован местный `config.toml`; папка `desktop/dist/windows` в git не входит. Её нужно перенести на компьютер, где уже открыт Хаб, и запустить `HomeMusic.exe` двойным щелчком. Мини, очередь в среднем окне и альбом в большом здесь не проверялись. Пока программа лежит в `target/`, она по-прежнему читает `config.toml` из папки исходников.

## Не делаем

- Свой звуковой декодер.
- Эмбеддер, миксы и ассистента внутри плеера. Это остаётся в Хабе.
- Редактор скинов AIMP. Рисуем свои три раскладки, а не загружаем чужой `.acs`.
